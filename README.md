# Prompt Fit Loop

一个有限轮项目质量闭环 Skill。它会根据用户提供的满意标准制作成果、自动评分，并在未达标时继续修改，最终生成完整日志。

> 仅通过 `$prompt-fit-loop` 显式调用。  
> 当前面向 Codex 开发和测试，其他 Agent 平台需要适配。

## 功能

- 提取项目要求、交付物和用户满意标准。
- 完成代码、网页、文档、数据、设计等具体成果。
- 使用实际证据评分；关键要求未满足时不能通过。
- 未达标时自动修改，最多 5 轮。
- 项目结束后生成完整流程日志。

## 适用范围

适用于有具体交付物和验收要求的项目。不适用于纯聊天、咨询、头脑风暴或没有具体成果的任务。

## 获取 Skill

可以通过以下方式获取 `prompt-fit-loop` 文件夹：

- 在仓库的 Releases 页面下载版本压缩包。
- 点击仓库页面的 Code 按钮，选择 Download ZIP，解压后取得 prompt-fit-loop 文件夹。
- 使用 Git Clone 获取完整仓库。

实际使用的 Skill 位于：

```text
prompt-fit-loop/
```

请保留该文件夹中的 `SKILL.md`、`agents/`、`references/` 和 `scripts/`。

## 使用

```text
$prompt-fit-loop

项目想法：制作一个任务管理网页
用户满意标准：
- 支持新增、完成和删除任务
- 刷新页面后任务仍然存在
- 页面布局清晰
满意度阈值：0.85
最多轮数：3
```

默认满意度阈值为 `0.80`，允许 `0.50–0.95`。默认最多 `3` 轮，最高 `5` 轮。

## 注意事项

- “AI 参考满意度”不等于真实用户满意度。
- 达到最多轮数后仍未通过时，会停止并报告剩余问题。
- 不要在项目或日志中提交密码、令牌和私钥。
- 不保证在其他 Agent 平台直接运行。
